# 建筑概念图工作流

> 从一张场地照片或一个粗糙体块，到能放进作品集的概念图。
> 以 ComfyUI + SDXL 为主，FLUX 同理，参数按 4060 8G 实测。

---

## 0. 先想清楚：这张图要表达什么

概念图不是渲染图，评委/老师看的是**一个想法**。动笔（动鼠标）之前先定：

- **主体**：一个体量关系？一种材料？一处场景氛围？
- **视角**：人视（代入感）/ 半鸟瞰（体量）/ 鸟瞰（总图关系）
- **一眼能读到什么**：入口在哪、主次关系、和场地怎么接

选错视角，后面所有 AI 操作都在补救。**半鸟瞰 30°~45°** 是最不容易出错的角度。

---

## 1. 出骨架：体块 or 照片

两条路，选一条：

### A. 体块路线（推荐，透视最准）

1. **Blender + BlenderGIS**：导地形、卫星图，拉出场地。
2. 用最简单的白模搭体量，**不要贴材质**——AI 会把白模理解成"待赋材质的建筑"。
3. 相机：35~50mm 等效，人眼高度 1.6m 或半鸟瞰 20~30m。
4. 截图前打开**阴影**（有一点点方向光，AI 才知道哪面是受光面）。

### B. 照片路线（改造类项目）

1. 现场照片要求：**水平、建筑占画面 60% 以上、不要逆光**。
2. `Informative Drawings` 转线稿 → 得到干净轮廓。
3. 或者直接照片进 `Depth-Anything` 提深度。

> 两条路都可以混：照片做背景，白模放前景。

---

## 2. 提控制图

在 ComfyUI 里用 `comfyui_controlnet_aux` 节点，一次出三张：

| 控制图 | 节点 | 适合 | 权重建议 |
|---|---|---|---|
| **MLSD** | `M-LSD Lines` | 建筑直线、体块轮廓 | 0.8~1.0（最强） |
| **Depth** | `Depth Anything` | 前后层次、空间进深 | 0.6~0.8 |
| **Canny / Lineart** | `Canny` / `Lineart` | 精确边缘（窗框、栏杆） | 0.5~0.7 |

**关键经验**：MLSD 的直线阈值调低一点，别让它把树的枝叶也画成直线。
`M-LSD` 节点里有 `score_threshold` 和 `dist_threshold`，前者 0.1、后者 0.1 起步，出图后再微调。

---

## 3. 出图：ComfyUI 基本盘

```
Checkpoint (SDXL 写实类)
   ├─ Positive: 描述空间/材料/光线（不是描述"建筑"两个字）
   ├─ Negative: 通用负面词
   ├─ ControlNet ×2（MLSD 主 + Depth 辅）
   ├─ IPAdapter（可选，喂 1~3 张风格参考）
   └─ KSampler → VAE Decode → Save
```

**参数起点（SDXL，1024×1024）**

| 项目 | 值 | 说明 |
|---|---|---|
| steps | 28~32 | 再多收益很小 |
| cfg | 5.0~7.0 | 建筑要"听话"，别超过 7.5 |
| sampler | DPM++ 2M Karras | 稳定 |
| denoise | 1.0（纯生成）/ 0.45~0.6（img2img 改图） | |
| 分辨率 | 1024×1024 或 1216×832 | 横图做场景，竖图做立面 |

**提示词写法（建筑专用）**

不要写 "a beautiful building"——AI 会给你一个商场。

```
low-rise concrete gallery, deep cantilever, floor-to-ceiling glazing,
board-formed concrete, weathered steel panel, overcast diffuse light,
wet pavement reflection, sparse planting, human scale figures,
architectural photography, 35mm, eye level, muted palette
```

结构：**类型 → 体量动作 → 材料 → 光 → 环境 → 人 → 摄影语言**。
负面词里放 `text, watermark, cartoon, oversaturated, fisheye, distorted perspective`。

---

## 4. 让它"成套"：统一风格

一整套方案图最忌讳每张调子不一样。

- 固定一个 **Checkpoint**，不要中途换模型。
- 用 **IPAdapter** 喂同一组参考图（3 张以内），权重 0.6~0.8。
- 固定 seed 换视角时，只改 ControlNet 输入，不改提示词主干。
- 后期统一在 Krita 里套一个 LUT / 曲线。

---

## 5. 修：局部重绘

AI 出图 90% 会在这些地方犯错，用 `ComfyUI-Impact-Pack` 的 Detailer 或手动 inpaint：

| 问题 | 修法 |
|---|---|
| 窗户数量/排布乱 | 框选立面，inpaint，denoise 0.5，提示词只写 `evenly spaced windows` |
| 人物比例怪 | 直接 inpaint 掉，后期在 Krita 里贴真人物 |
| 树冠糊成一团 | 抠掉重生成，或后期贴素材 |
| 天空太平 | 单独 inpaint 天空，`dramatic overcast sky` |
| 透视轻微歪 | Krita 里用透视变形工具拉正，比重新生成快 |

---

## 6. 放大与交图

1. `Real-ESRGAN` 放大 2×（1024 → 2048），显存不够就分块。
2. `chaiNNer` 可以整文件夹批处理（方案图一出一组时省事）。
3. Krita 里做最后三件事：**压暗四角**（视觉聚焦）、**加一层很淡的雾**（空气感）、**统一色温**。
4. 导出：作品集用 sRGB JPG 质量 90；打印用 TIFF 300dpi。

---

## 常见坑

**1. AI 味太重**
原因通常是：过饱和、材质太干净、没有杂物、光线太均匀。
解法：加 `dust, minor imperfections, weathering`，后期加噪点，别用"完美"的 HDRI 光。

**2. 透视崩**
一定是 ControlNet 权重不够或控制图不干净。MLSD 权重拉到 1.0，先把白模截干净再喂。

**3. 尺度感丢失**
AI 不知道你的建筑多高。解决办法只有两个：**放人**（1.7m 参照）+ **放已知尺寸的物件**（车、栏杆、砖缝）。

**4. 中文标注乱码**
SDXL 基本写不对中文。要么后期在 Inkscape/PS 里加字，要么用 `Qwen-Image` 这类中文强的模型专门出带字的图。

**5. 出图很慢**
8G 显存先降分辨率到 768 出草图，选中方案的再精修放大。别一上来就 2K。

## 一周练习建议

| 天 | 任务 |
|---|---|
| 周一 | 装 ComfyUI + Manager，跑通官方示例 |
| 周二 | 白模 → MLSD → 出 10 张，只调提示词 |
| 周三 | 加 Depth 和 IPAdapter，做同一方案的 4 个视角 |
| 周四 | 学局部重绘，修窗户和天空 |
| 周五 | 完整走一遍：现场照片 → 线稿 → 出图 → 放大 → Krita 收尾 |
| 周末 | 挑 3 张放进作品集，写清楚"哪一步用了什么工具" |

> 面试/答辩时，"我用 ControlNet 的 MLSD 控制体块、Depth 控制进深、IPAdapter 统一材质"——这句话本身就证明你懂流程，比"我会 AI 出图"值钱得多。
